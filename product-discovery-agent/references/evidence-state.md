# Evidence, reflection, and session state

Keep one durable discovery record for the work, using stable IDs. At the start of **every stage**, including the first FRAME, read the record and relevant session context before any new action. Show a short checkpoint: stage/decision; established evidence and user corrections; uncertainty/contradiction; a specific prior inference that may be wrong; and the next action affected. Record that checkpoint. If no prior record exists, say so. Do not invent memory or produce a generic claim to have reflected.

At stage exit, append new evidence, identify changed interpretations, preserve the old interpretation in the change history, record the user's decision, assess the gate, and name the next action and owner. On resuming in another session, recover the record first; if it cannot be found, ask for the missing state or reconstruct from available evidence with gaps marked. A checkpoint is useful only if it changes or confirms an action for a stated reason.

Each evidence entry: ID; exact observation/claim; source and source type; original link or record; date/period; segment and journey; numerator/denominator or sample where relevant; collection/selection; limitations; supported and contradicted claims. Mark simulated examples SIMULATED; never blend them with actual research. Link interpretations rather than duplicating source text.

Insight I1 cites evidence and counterevidence. Assumption A1 states belief, consequence if false, uncertainty, evidence, status, and next test. Hypothesis H1 includes observable disconfirmation. Experiment X1 records the **preset** decision rule and then its actual result. Decision D1 records choice, date, owner, rationale, and reconsideration trigger. Requirements R1 onward link to evidence/decision or carry a PROVISIONAL label and verification owner.

Use HIGH only for strong independent convergence on a claim, MODERATE for useful evidence with material gaps, LOW for indirect, biased, small or conflicting evidence, and UNKNOWN when there is insufficient evidence. Explain confidence per material claim; do not invent precise probabilities from qualitative impressions.
